## Worked Solutions

**Q1.** Binary 10110 → Decimal: 1·16 + 0·8 + 1·4 + 1·2 + 0·1 = 22. **Answer: b) 22**

**Q2.** A + A’B = (A + A’)(A + B) = 1·(A + B) = A + B; taught as part of the Absorption family. **Answer: b) Absorption Law**

**Q3.** 3A₁₆ = 3·16 + 10 = 48 + 10 = 58. **Answer: a) 58**

**Q4.** Group in 3s from the right: 110 101 = 6 5. **Answer: b) 65**

**Q5.** 190 ÷ 16 = 11 remainder 14 → B E. **Answer: b) BE**

**Q6.** 10010 + 01101 = 11111 (no carry). **Answer: a) 11111**

**Q7.** 1010 + 0101 = 1111. **Answer: b) 1111**

**Q8.** 12 − 5 = 7 → 0111. **Answer: b) 0111**

**Q9.** Invert 0110 → 1001, then +1 → 1010. **Answer: b) 1010**

**Q10.** 4·256 + 11·16 + 2 = 1024 + 176 + 2 = 1202. **Answer: a) 1202**

**Q11.** F=1111, 5=0101 → 1111 0101 1111 0101. Decimal: 15·4096 + 5·256 + 15·16 + 5 = 62965. **Answer: a)**

**Q12.** 2³ = 8 cells. **Answer: b) 8**

**Q13.** Valid groups are powers of 2 (1, 2, 4, 8, 16…); 3 is not. **Answer: c) 3**

**Q14.** Grouping the 1-cells covering A and the column where C = 0 (C̄) yields F = A + C̄. **Answer: c) F = A + C̄**

**Q15.** Factor A: A(B + B’) = A·1 = A. **Answer: b) A**

**Q16.** Expand: A + A·B’ + A·B + B·B’ = A + A(B + B’) + 0 = A. **Answer: a) A**
